# AIGlassAware GitHub Pages

Public repository: `https://github.com/glzlaohuai/aiglassaware-site`

Published site: `https://aiglassaware.hiimobapps.com/`

The repository contains only the marketing, privacy, and support pages used by
the App Store listing. The iOS application source remains separate.

GitHub Pages serves the site from the `main` branch. The custom subdomain is a
CNAME to `glzlaohuai.github.io`; the `hiimobapps.com` apex remains untouched.
